Changelog do QuickNote CRM

Acompanhe cada entrega por área ou busque diretamente pelo recurso implementado.

Seletor de Notas com Busca e Prévia

23/11/2026 • PR #31
  • Busca instantânea nas notas: a antiga faixa horizontal de botões deu lugar a uma lista vertical com busca por título ou conteúdo, sem se preocupar com acentos ou letras maiúsculas.
  • Mais contexto antes de abrir: cada item agora mostra um trecho da anotação, há quanto tempo foi editado e um indicador quando a nota já está vinculada a um negócio no Pipedrive.
  • Navegação pelo teclado: troque de nota rapidamente usando as setas, Enter para abrir e Esc para fechar apenas o seletor.

Liberação no Mac e Documentação Alinhada

23/11/2026 • PR #28–#29
  • Instalação mais simples no macOS: o pacote do app agora recebe assinatura ad-hoc completa, evitando que o Gatekeeper acuse o arquivo como danificado e permitindo liberar a abertura em Ajustes do Sistema → Privacidade e Segurança.
  • Guias e README atualizados: documentação revisada para refletir exatamente os componentes atuais e deixar claro que o envio real de dados está ativo no Pipedrive, enquanto n8n e Supabase seguem em preparação.

Notas de Versão Automáticas nos Lançamentos

22/11/2026 • PR #27
  • Histórico de mudanças organizado: o projeto agora gera automaticamente um registro claro em português com todas as novidades, melhorias visuais e correções de cada versão.
  • Releases mais completas: ao publicar uma nova versão, a página de download passa a exibir automaticamente o resumo do que mudou junto aos instaladores.

v0.1.0 — Instaladores Multi-OS e Ajustes na UI

Novembro 2026 • PR #23–#25
  • Configuração na própria interface: URLs e chaves de Pipedrive, n8n e Supabase salvas no SQLite local pela aba de Ajustes.
  • GitHub Releases automático: instaladores para Windows (.exe/.msi), macOS (.dmg) e Linux (.AppImage/.deb).
  • Customização do dock: ajustes de aparência e contraste no tema claro.

Etapa 4 — Integração com Pipedrive

PR #14–#15
  • Busca de deals: pesquise negócios do Pipedrive no dock e associe à nota.
  • Notas e Atividades: publique registros direto no negócio selecionado.

Visual — Paleta Azul-Marinho & Roxo

PR #6, #13, #21
  • Tema escuro dedicado: azul-marinho profundo com destaque roxo para botões principais.
  • Layout compacto: melhorias de contraste e redimensionamento do dock.

Etapas 1–3 — Base do Produto

PR #1–#7, #22
  • Dock lateral Tauri v2: aplicativo leve ancorado na borda da tela.
  • Notas, To-dos e CI: persistência local em SQLite e suíte de testes automatizados.
